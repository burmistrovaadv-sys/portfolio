# Портфолио — Анастасия Бурмистрова

Статический сайт-портфолио продуктового дизайнера. Чистые HTML, CSS и JS,
без сборки, без фреймворков и без внешних зависимостей во время работы сайта.

## Что где лежит

```
index.html                        главная: герой, 6 кейсов, о себе, контакты
404.html                          страница «не найдено»
robots.txt, sitemap.xml           для поисковиков
cases/
  sohranenie-kontaktov.html       страница кейса IronWallet
assets/
  styles.css                      стили главной и общие
  case.css                        стили страницы кейса
  app.js                          появление блоков при скролле
  case.js                         подсветка активного пункта оглавления
  favicon.svg                     иконка вкладки
  img/                            картинки кейсов и фото, экспорт x3
  fonts/                          Onest и Martian Mono, локальные woff2
tools/
  fetch-fonts.mjs                 разовый скрипт для обновления шрифтов
```

## Как открыть локально

Просто дважды кликнуть по `index.html` — сайт откроется в браузере.
Если хочется «как на сервере» (чтобы работали пути от корня в `404.html`):

```
npx serve .
```

## Шрифты

Шрифты скачаны и лежат рядом с сайтом, а не подгружаются с Google Fonts —
так страница открывается быстрее и не зависит от доступности CDN.
Обновить их можно командой `node tools/fetch-fonts.mjs` (нужен Node.js).

## Перед подключением своего домена

Сейчас во всех адресах указан `https://portfolio-liart-delta-79.vercel.app`.
После подключения своего домена его нужно заменить в этих файлах:

- `index.html` — теги `canonical`, `og:url`, `og:image`
- `cases/sohranenie-kontaktov.html` — то же самое
- `robots.txt` — строка `Sitemap:`
- `sitemap.xml` — все адреса `<loc>`

## Деплой

Сайт статический, собирать нечего. Vercel берёт файлы из репозитория как есть:
Framework Preset — **Other**, Build Command — пусто, Output Directory — пусто.

Любой `git push` в ветку `main` автоматически обновляет сайт.

`vercel.json` включает адреса без `.html` и долгий кеш для шрифтов и картинок.
