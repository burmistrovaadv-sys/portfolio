# Портфолио — Анастасия Бурмистрова

Статический сайт-портфолио продуктового дизайнера. Чистые HTML, CSS и JS,
без сборки, без фреймворков и без внешних зависимостей во время работы сайта.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | главная: герой, два кейса, шоты, о себе, контакты |
| `/japanstat` | та же главная, но с обращением «Привет, JapanStat и Banzai24!». Закрыта от индексации (`noindex`) — это страница под конкретный отклик |
| `/send-flow` | кейс «Сохранение контактов», IronWallet |
| `/crypto-directory` | кейс «Crypto Directory» |

## Что где лежит

```
index.html                  главная
japanstat/index.html        главная с приветствием (noindex)
send-flow/
  index.html                кейс «Сохранение контактов»
  img/                      макеты кейса
crypto-directory/
  index.html                кейс «Crypto Directory»
  img/                      макеты кейса
404.html                    страница «не найдено»
robots.txt, sitemap.xml     для поисковиков
vercel.json                 адреса без .html, редиректы, кеш
assets/
  main.css                  стили главной и /japanstat
  case.js                   табы, просмотр картинки, подсветка оглавления
  favicon.svg               иконка вкладки
  cv-anastasia-burmistrova.pdf  резюме, открывается по ссылке «CV» в шапке
  img/                      картинки главной, экспорт x3
  fonts/                    Onest и Martian Mono, локальные woff2
tools/
  fetch-fonts.mjs           разовый скрипт для обновления шрифтов
```

Стили кейсов лежат прямо внутри их `index.html`. Это сделано намеренно:
у двух кейсов одинаково названные, но по-разному настроенные блоки
(`.frame`, `.media`), и общий файл сломал бы вёрстку одного из них.

Все пути к картинкам и файлам — от корня (`/send-flow/img/...`), а не
относительные. На Vercel адрес страницы выглядит как `/send-flow` без слэша
на конце, и относительный путь `img/...` искал бы картинку не там.

## Картинки

Все картинки на страницах — в формате **WebP**. Исходные PNG весили 38,5 МБ,
после конвертации стало 4,6 МБ при той же чёткости: самая большая сторона
ограничена 3000 px (макет показывает картинку максимум в 1037 px, то есть
запас почти трёхкратный), качество 85.

PNG остались только два — `assets/img/c1.png` и `send-flow/img/hero.png`.
Это картинки для превью при отправке ссылки в мессенджер: часть соцсетей
до сих пор не понимает WebP.

Если понадобится пересобрать картинки из новых исходников: положить PNG
в нужную папку `img/` и сконвертировать любым конвертером в WebP с теми же
настройками, а в HTML поправить `width`/`height` на новые размеры.

## Как открыть локально

```
npx serve .
```

Открывать двойным кликом по файлу не стоит: пути от корня (`/assets/...`)
в этом режиме не работают.

## Шрифты

Шрифты скачаны и лежат рядом с сайтом, а не подгружаются с Google Fonts —
так страница открывается быстрее и не зависит от доступности CDN.
Обновить их можно командой `node tools/fetch-fonts.mjs` (нужен Node.js).

## Домен

Основной адрес сайта — **https://www.anastasia-burmistrova.ru**

Домен куплен в nic.ru, а DNS делегирован на Vercel (`ns1.vercel-dns.com`,
`ns2.vercel-dns.com`). Это значит, что все записи домена настраиваются
в самом Vercel, а в nic.ru больше ничего трогать не нужно.
Сертификат HTTPS Vercel выпускает и продлевает сам, покупать не надо.

Адрес без `www` и адрес по `http://` автоматически перекидывают на основной.
Старый адрес `portfolio-liart-delta-79.vercel.app` тоже продолжает работать.

Если домен когда-нибудь поменяется, его нужно заменить в этих файлах:

- `index.html`, `japanstat/index.html` — теги `canonical`, `og:url`, `og:image`
- `send-flow/index.html`, `crypto-directory/index.html` — то же самое
- `robots.txt` — строка `Sitemap:`
- `sitemap.xml` — все адреса `<loc>`

## Деплой

Сайт статический, собирать нечего. Vercel берёт файлы из репозитория как есть:
Framework Preset — **Other**, Build Command — пусто, Output Directory — пусто.

Любой `git push` в ветку `main` автоматически обновляет сайт.
